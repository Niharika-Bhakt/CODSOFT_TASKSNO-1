# Job Board 💼

### Find Jobs. Apply. Hire.

Job Board is a full-stack job portal designed to make job searching, applying, and recruitment simple and efficient. Job seekers can explore and apply for suitable opportunities, while employers can post and manage job openings.

---

## ✨ Features

- 💼 Browse available job openings
- 🔍 Search for specific jobs
- 📄 View detailed job information
- 👨‍💼 Employer dashboard for posting and managing jobs
- 👤 Candidate profile and application management
- 📝 Job application with resume upload
- 📊 Track job applications
- 📧 Email notifications for applications and updates
- 🔐 User Login and Sign Up
- 🛡️ Secure user authentication
- 📱 Responsive design for different devices

---

## 🛠️ Tech Stack

| Part | Technology |
|------|------------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas |
| Authentication | JWT |

---

## 🎮 How It Works

1. Create an account or log in.
2. Browse available job opportunities.
3. Search for suitable jobs.
4. View complete job details.
5. Apply for a job and upload your resume.
6. Track your applications.
7. Employers can post and manage job openings.
8. Candidates can receive updates about their applications.
